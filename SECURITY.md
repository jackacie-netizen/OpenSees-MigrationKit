# Security policy

## Supported versions

Security fixes are provided for the latest released version when practical. Version 0.1.0 is early-stage research tooling.

## Reporting a concern

Do not open a public issue containing credentials, private model data, or exploit details. Use GitHub's private vulnerability-reporting feature when it is available. If it is unavailable, open a minimal public issue requesting a private maintainer contact without including sensitive details.

Do not attach proprietary model files or unpublished research data to a report.
