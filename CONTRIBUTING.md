# Contributing

Thank you for helping improve OpenSees-MigrationKit.

1. Open an issue describing the comparison behavior or documentation change.
2. Keep changes publication-safe and independent of confidential or unpublished models.
3. Add a failing test before changing behavior, then make the smallest implementation that passes.
4. Run `python -m pytest -v` and include the result in the pull request.
5. Do not change tolerances or expected values merely to make a failing comparison pass.

Contributions must be compatible with the BSD 3-Clause License. Automated checks support review but never constitute engineering approval.
